# どうぶつしょうぎ 評価グラフ

Android版「どうぶつしょうぎ」（`jp.co.gmode.dobutsushogi`）向けのLSPosedモジュールです。対局画面に形勢グラフと3×4のミニ盤面を表示し、Rustによる局面評価と完全解析表（WDL/DTM）の参照に対応します。
